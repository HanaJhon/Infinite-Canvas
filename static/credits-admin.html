账号管理 API 设置

汇率与记账

1 积分值多少钱，只影响「充值套餐」的换算提示；模型单价仍是「积分」。

默认「只记账不拦截」：即使余额为 0，模型照常运行，流水里记负数。想强制收费再勾第二项。

注册限制

注册页会按这里的设置显示必填项；管理员账号与第一个账号不受限制。手机号注册已移除，只保留邮箱。

邮箱范围限制
邮箱白名单 / 黑名单可写「完整邮箱」或「域名」。开启「注册需要邮箱验证码」后，用户必须先在注册页点「获取验证码」，把收到的 6 位数字填回去并通过校验，才能注册成功（需先在下面配好发信服务器）。

邮箱验证码 · 发信服务器

注册验证码通过 SMTP 发送。QQ 邮箱 / 163 需先在邮箱后台开启 SMTP 并拿到「授权码」（不是登录密码）。

测试会使用「当前已保存」的配置：改完服务器信息请先点下面「保存全部设置」再测试。授权码保存在本机 data/credits_settings.json，不会回显。

模型积分额度

模型单价已经搬到 API 设置 · 模型积分额度（2026-11-05 起在那里统一维护）。这里只保留汇率、注册限制、充值套餐和收款方式。

充值套餐

成员在「我的积分」里看到的可选额度。价格只用于展示和收款核对。

收款方式

上传收款二维码，或填一个收款链接（PayPal.me 等）。成员提交充值申请时会看到这些。

二维码上传后会存到服务器的 assets/pay/ 目录，返回的地址自动填进左边的输入框。
