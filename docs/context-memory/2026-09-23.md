老板原话：「安装成功的技能似乎没有做分类，也没有提供卸载显示，支持用户随时卸载」。

### 1.1 现状摸底（先查清楚再动手）

- 后端**已有** `POST /api/skills/uninstall` 与 `GET /api/skills/installed`；前端**只有**市场卡片上的

  1. **从全站搜索装的 Skill（如 caveman）不在内置清单 `state.skills` 里** → `applyInstalled()`

  `installed` 双保险）；安装/卸载后同步 `state.installed` 与角标。

## 二、Agent 对话新增「/ 命令面板」与 192k 上下文自动压缩

老板需求：「当用户发送/时自动显示已安装可调用的skills，用户可以触发skills效果，agent中内置自动压缩上下文能力当前对话中上下文达到192ktoken的时候自动压缩上下文，也添加主动压缩功能加入到skills中，用户可以发送/进行选择触发」。

### 2.1 现状与方案

1. **已安装 Skills 原先未接进聊天 Agent**：
   - 之前只有画布 Agent（`run_agent_llm_task`）注入了 `installed_skills_prompt_block()`；
   - 聊天 Agent（`POST /api/chat/agent`，`gpt-chat.html`）的系统提示词只有基础的 `chat_system_prompt`，完全没接入已安装 Skill。
2. **上下文管理原先只有硬截断**：
   - `conversation["messages"][-MAX_HISTORY_MESSAGES:]`（默认 30 条），一旦超出早期消息直接丢失，无摘要也无 token 统计。
3. **实现方案**：
   - **Token 估算**：无三方依赖的离线估算器 `estimate_tokens`（CJK 字符 2 tokens，其他 4 字符/token；偏向高估，避免越界才触发）。
   - **自动压缩**：`maybe_auto_compress` 在估算达到 192k token（`AUTO_COMPRESS_TOKEN_THRESHOLD=192000`）时，调用对话模型（或回退抽取）把早期消息压缩为一条系统摘要消息并落盘；前端收到 `auto_compressed: true` 弹出 toast。
   - **`/` 命令面板**：输入框输入 `/` 时弹出面板，常驻「压缩上下文」动作，并从 `/api/skills/installed` 列出所有已安装的 Skill；支持键盘 ↑↓ 选择、Enter 触发、Esc 退出，实时文本过滤。
   - **主动激活 Skill**：发送 `/skill <id|名称>` 把目标 Skill 标记为当前会话的 `active_skill`，其完整 SKILL.md 优先注入系统提示词；发送 `/skill off` 解除。
   - **主动压缩**：发送 `/compress` 立即触发当前对话历史的压缩。

### 2.2 涉及文件与验证

## 三、Agent 对话「/」命令与 Skill 选择浮窗修复（纳入 v1.1.6）

老板反馈截图：发送 `/skill caveman-...` 指令后端激活正常，但在输入框键入 `/` 时未见任何 Skill 浮窗弹起。

### 3.1 根因分析
1. **DOM 容器裁切（主因）**：`.slash-palette` 原先作为 `.composer` 的直接子节点，采用 `position:absolute; bottom:calc(100% + 10px)`。然而 `.composer` 容器自身声明了 `overflow:hidden`（以及圆角截断），导致浮在外部的面板被浏览器彻底裁剪隐藏。项目已有的 `.agent-tools-popover` 等均已采用移动至 `document.body` + `position:fixed` 定位的通用规范方案。
2. **暗黑模式样式缺失**：老板截图中处于暗黑主题环境，`.slash-palette` 缺少暗黑模式（`theme-dark` / `studio-theme-dark`）下针对浮层背景、描边、毛玻璃阴影以及 active/hover 项高亮、标签 chip 的专用适配样式。
3. **图标定义失效**：`/compress` 上下文压缩条目指定的图标为 `icon: 'compress'`，但项目内置的 Lucide 图标库 v1.16.0 中不存在 `compress` 图标（仅存在 `minimize-2` / `minimize`），导致图标空白。
4. **视口交互与生命周期**：缺少外部空白区域点击自动关闭、以及视口缩放（`visualViewport`）及窗口 resize 时的浮窗位置重算。

### 3.2 修复与优化措施
- **`static/gpt-chat.html`**：
  - CSS 将 `.slash-palette` 调整为 `position:fixed; z-index:9999;`，利用 CSS 变量 `--slash-left`、`--slash-top`、`--slash-width` 动态跟随定位。
  - 新增暗黑模式（`html.studio-theme-dark body .slash-palette` 等 4 个选择器组合）配色，覆盖面板底色、描边、阴影与项目选中态。
  - 打开浮层时如果 `pal.parentElement !== document.body`，将其安全移动至 `document.body`，并在关闭时移回 `.composer` 维持 DOM 干净整洁。
  - 实现 `positionSlashPalette()`：基于输入区 `.composer` 的 `getBoundingClientRect()` 计算横向与纵向坐标，向上浮动在输入框正上方，并根据 `window.visualViewport` 确保不超出可视区域边界。
  - 绑定 `document` 的全局点击事件，支持外部空白区域点击收回浮窗；监听窗口及 `visualViewport` 的 `resize` / `scroll` 实时调整位置。
  - 将 `/compress` 图标修正为经过验证支持的 `minimize-2`。
- **版本递增与打包发布**：
  - 执行 `tools/bump_version.py`，版本递增至 `1.1.6`；
  - 更新 `static/update-notes.json` 及编写 `output/RELEASE_NOTES-1.1.6.md`；
  - 执行 `tools/release.py build --notes-file output/RELEASE_NOTES-1.1.6.md` 构建官方发布包：全量包 `Infinite-Canvas-Full-1.1.6.zip`（111.51 MB）、增量更新包 `Infinite-Canvas-Update-1.1.6.zip`（0.12 MB）、更新元数据 `update.json`；
  - 发布包内置 `scan_release.py` 自动化安全审计 0 命中通过；
  - 本地 git 提交变更：`683e67a`。
