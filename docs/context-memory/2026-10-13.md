## §2 混元3D 节点按 3D预览 风格重做 + 拖拽/下载/显示样式（老板反馈）

### 三个问题的根因与修法
1. **节点「裸」在黑底上、拖不动** —— 3D 节点的框架/头部/body 布局 CSS **全部以 `.smart3d-node` 为作用域**
   （`.image-node.smart3d-node{padding/bg/border/shadow}`、`.smart3d-node .node-body{...}`），
   而 hy3d 节点只有 `smart-hy3d-node` 类 ⇒ 一条样式都没吃到。同时**可见区域（舞台 + bar）恰好都在
   `beginNodeDrag` 排除名单里**（`.smart3d-stage, .smart3d-bar`）⇒ 100% 无法拖动。
   **修**：渲染时 hy3d 节点同时带 `smart3d-node`（`sync3DViewers` 对无 `[data-3d-stage]` 的节点直接 return，安全）。
2. **黑底** —— 只建了环境贴图，**没设 `scene.background`、没调 `build3DStudioLights`**（3D 节点在 `apply3DSceneToViewer` 里做）。
   **修**：`scene.background = new THREE.Color(SMART_3D_STUDIO.background)` + `build3DStudioLights(viewer, null)`
   + GLB 组里加 `ShadowMaterial` 接触阴影地面（**必须在算完取景框之后加**，否则 80×80 平面把包围盒撑爆）。
3. **缺下载/显示样式** —— 新增：下载（`<a download>` 复用 `.smart3d-run` 外观，**不能 preventDefault**，否则下载被吞）
   + 工具行 9 键（自动旋转/纹理/白模/线框+白模/反照率/法线/包围盒/光照/适配视图）+ 焦距滑杆（复用 `smart3DFocalMm`）。

### 其他
- 🚨 **模型加载只在「下一次 render」才触发**（viewer 异步建）⇒ 探针只 render 一次时舞台空白。
  **修**：`createHy3dViewer` 建完自己调 `loadHy3dModelIntoViewer`（自包含）。
- 材质切换：原始材质存 `mesh.userData.hy3dOriginal`；clay/wireframe/normal 用 viewer 级共用材质（随 viewer dispose），
  反照率每 mesh 一份存 `userData.hy3dAlbedo`（dispose 时单独清）。
- `hy3dLights` 默认「开」（undefined 视作 true）⇒ 开关语义用 `node[key] === false`，不能用 `!undefined`。
- 自动旋转：`start3DRenderLoop` 加通用钩子（`viewer.autoRotate` 时每帧 `orbit.theta += 0.01` 并置脏）。
- 默认取景收紧到距离 ~4.9（原 6.2 显得空）。

## §5 分享不跳转根治 + 剩余次数显示（老板反馈）

### 分享不跳转的根因（**不是** window.open 被拦）
- 启动器 WebView2 **没有 NewWindowRequested 处理**（已核 `launcher/Program.cs` 无该事件），
  但 WebView2 的默认行为是「未处理 ⇒ 交给系统默认浏览器」⇒ `window.open` 本身可用
  （在线 PS 一直能用就是证据）。
- 真因：**任务记录只在内存里（`HY3D_TASKS`），服务一重启老节点的 `/api/hy3d-tasks/{id}/share` 就 404**；
  而 §4 之前的节点也没有 `result.share_url` ⇒ 点分享必然失败。
- **修**：新增 `POST /api/hy3d-share {asset_id}` —— **按资产 ID 分享，与任务记录解耦**
  （assetId 持久化在节点的 `hy3dAsset.id` 上，服务重启后照样能分享）。
  前端 `hy3dShareNode` 兜底链：`hy3dShareUrl` → `/api/hy3d-share(assetId)` → `/api/hy3d-tasks/{id}/share`。
- 链接拿到后 `scheduleSave()` 落盘，下次直接是 `<a>` 秒跳。

### 剩余次数（混元3D 积分）
- 客户端 `fetch_quota()`：页面内 POST `/api/3d/quotainfo {"sceneType":"3dCreations"}` → `{remain,total,consume,date}`。
- 🚨 **绝不写死数值**（各账号不同）：生成任务开始时顺手读（同会话零成本，写进 `task.quota` 与 `result.quota`）；
  另给 `GET /api/hy3d-quota?refresh=1`（开浏览器实时读，60s 缓存防连点）。
- 前端：bar 里「剩余 N 次」chip（`data-hy3d-quota`），点击刷新；提示气泡显示 `剩余/总` + `已用 N`。
- i18n +5（`hy3dQuota` / `hy3dQuotaTitle` / `hy3dQuotaUsed` / `hy3dQuotaLoading` / `hy3dQuotaFail`）= 1336 keys。
