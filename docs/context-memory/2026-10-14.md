### 背景

### 与旧实现的根本区别（方案的核心）
| 维度 | 旧 | 新 |
|---|---|---|
| 默认元素层 | `mode='model'` **整图交给图像模型重绘**（贵、必然不保真） | **原图像素轨道**：RGB 取自原图、只改 alpha；**0 次生图调用** |
| 任务形态 | 一个任务跑到底 | **两段**：分析（0 次调用）→ `review` → 按预算修复 |
| 额度 | 无 | 0/1/3/5/自定义，**后端原子扣减** |
| 质量 | 只给一个还原度分 | **问题清单**（kind/label/priority/local_fixable/detail） |
| 来源 | 只有 method | 每层 `provenance`（source/local_repair/ai_repair/text_editable/...） |
| 文字 | 只有编辑态 | **双轨**：默认显示原始像素 + `raster_backup_url` + `quad` 四边形 |
| 背景 | 本地挖洞 / 一次模型 | **三级**：本地直接恢复 → 本地局部修补 → 模型补全（provenance 区分） |

### 后端（main.py，+1164/-216）
- **新 schema v2**：`{version:2, phase, source:{sha256,width,height,mode,exif_orientation,dpi},
  canvas, budget:{limit,used,remaining}, layers:[{id,kind,z,name,bbox,url,source_url,generated_url,
  mask_url,provenance,quality,...}], repairs:[], audit:{checks,issues}}`。
- **SplitLayersBudget**：`spend()` 原子扣减（Lock），`can_spend/snapshot`；**失败不退还**（上游可能已计费）。
- **本地保真拆分**：`split_build_local_mask`（flood-fill 抠图 + `split_mask_clean` 形态学清理 + 夹回 bbox
  + hints 涂抹）→ `split_extract_pixel_track`（RGB 取自原图、alpha 二值）。
- **质量门禁** `split_quality_check`：reconstruction + z_order + 逐层 edge_check（半透明/孤立点/孔洞/
  fill_ratio/ring_delta）+ 主体缺失/截断 + 背景大空洞 → issues（`split_issue_priority` =
  面积×重要性×置信度×本地无法修复程度）。
- **预算调度器** `run_split_repair_task`：先 `split_local_repair`（换阈值重抠 / 更强形态学），
  再按优先级逐项 `split_ai_repair`（局部裁切 + 同尺寸 mask，只贴回遮罩区）；
  **前后 `split_issue_score` 对比，只有提升才采纳**，否则回退并记录。
- **新端点**：`POST /api/split-layers-tasks/{id}/repair`（预算修复）、
  `POST /api/split-layers-tasks/{id}/mask`（涂抹修正，纯本地）。
- **中间态**存 `SPLIT_TASK_STATE`（内存，最多 6 个）——重跑分析要花真钱，不能丢。
- 视觉分析（LLM）**不计入**图像模型预算（方案：视觉分析单独统计）。

### 🚨 本机环境坑（新增）
- **端口 3000-3080 被系统保留**（WinError 10013「访问权限不允许」）⇒ 测试服务改用 **8123**。
- **`[hidden]` 打不过类选择器**：`.sl-mask-bar{display:flex}` 会把 `hidden` 属性盖掉 ⇒
  必须显式补 `.sl-mask-bar[hidden]{display:none}`（本次真踩到，截图才发现）。
- 纯 PIL 环境（**无 numpy / cv2 / scipy**）⇒ 形态学只能用 `ImageFilter.MaxFilter/MinFilter`；
  **边界伪影**要靠「先零填充再运算、最后裁回」解决（否则四角会留下擦不掉的孤立点）。
