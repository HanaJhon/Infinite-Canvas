### 验证：exe 是压缩单文件包，字符串搜不到

`csproj` 里 `EnableCompressionInSingleFile=true` → **直接 grep exe 一定搜不到**（UTF-8 / UTF-16LE 都不行），
别据此判「没编进去」。两条有效路径：

1. **查编译中间产物**（未压缩、.NET 字符串在 `#US` 堆是 UTF-16LE）：
   `launcher/bin/Release/net8.0-windows/win-x64/InfiniteCanvasLauncher.dll` → 4 个 GPT 名字各 x1，
   负对照 `gpt-5.6-luna`/`gpt-5.5-pro`/`gpt-4o` 各 x0。
2. **解 .NET single-file bundle**（端到端）：manifest 条目结构实测为
   `off(int64) + size(int64) + csize(int64) + type(1 字节) + name(7-bit 长度前缀 + UTF-8)`，
   即**字段区在 name 前 25 字节**（⚠️ `type` 是 1 字节不是 4 字节，按 28 对齐读全是垃圾——踩过）；
   `zlib.decompress(d[off:off+csize], -15)`（raw deflate）→ 校验 `len==size` 且 `raw[:2]==b'MZ'`
   → 在 raw 里按 UTF-16LE 搜。本次 off=9928927、size=162304、csize=117996。
