老板：「允许用户在 3D 预览窗口通过滑块调节摄像机焦距」。落到 `.smart3d-bar`（已有运行按钮那行下面），用 range slider 控制 `viewer.camera.fov`，落盘到 `node.camera.fov`。

### 实现要点（8 处改动）
1. **i18n**：加 `smart.3dFov = {zh: "焦距", en: "Focal length"}`，i18n 校验通过。
2. **辅助函数**（`smart-canvas.js:9015`）：
   - `smart3DCurrentFov(node)`：优先 `node.camera.fov` → 场景 `camera.fov` → 45，并做 20–90 范围合法。
   - `smart3DFocalMm(fov)`：35mm 全画幅等效 `f = 12 / tan(fov/2)`（传感器高 24mm → half=12mm），边界保护 tan<=0 时回退 50。
3. **`smart3DBodyHtml` 加 fov 行**：在 `.smart3d-bar`（运行按钮之前）插入 `<div class="smart3d-fovrow">` 含滑块 + 读数 `<span data-3d-fovval>`。
4. **`bind3DNodeControls` 绑事件**：
   - `input`（实时）：`viewer.camera.fov = Number(value); viewer.camera.updateProjectionMatrix(); viewer.dirty = true;` —— 不写盘、不 scheduleSave，避免拖动过程反复触发 debounce 风暴。
   - `change`（松手）：写 `node.camera.fov` + `scheduleSave()`。
   - 必须 `e.stopPropagation()`，否则节点拖拽抢走鼠标事件（`beginNodeDrag` 的 `el.onmousedown` 排除链要相应放过 `[data-3d-fov]`）。
5. **`apply3DSceneToViewer` 加覆盖**（`smart-canvas.js:9264`）：场景加载时优先用 `node.camera.fov`，否则用场景默认。这样**刷新后焦距自动恢复**。
6. **`persist3DCamera` 加 fov 落盘**（`smart-canvas.js:9452`）：拖拽改角时也会把 `fov` 一并写入 `node.camera`。
7. **`bindNodeEvents` 排除链**：`.smart3d-fov, .smart3d-fovval` 加进 `[data-3d-provider], [data-3d-model], .smart3d-raw` 的排除集合。
8. **CSS**：`.smart3d-fovrow` flex 行 + `.smart3d-fov` range 滑块浅深主题适配（`accent-color: var(--accent)`，track/thumb 自定义）。

### 验证（用无头 Edge + 同源 iframe 探针）
**踩到的两个非功能坑（都已写入 `infinite-canvas-verify` 技能）**：
1. **WebGL 必须 SwiftShader**：`--disable-gpu` + headless=new 会让 `WebGLRenderer` 构造失败，但 JS 兜底把它吞了 → 表现 `hasScene` 永远是 false、`smart3DViewers.size` 永远 0。修法：`--enable-unsafe-swiftshader --use-gl=angle --use-angle=swiftshader`。
2. **`loadCanvas` 比 `iframe.onload` 晚约 3s**：画布页 `loadCanvas`（`smart-canvas.js:6751`）是异步 fetch，赋值 `nodes = canvas.nodes` 比 onload 晚。手动 `nodes.push()` 在 `waitFor(render)` 通过后立刻执行，会被 `loadCanvas` 的 0 节点覆盖 → `create3DViewer` 后续找不到节点、安静返回 null、无 error。修法：帧就绪后 `await sleep(3500)` 再注入，或用真实 `create3DNode()` + `scheduleSave()`。

**最终探针实测数据**（canvas `0b33f1c6`，节点 `3d_dhhuz02ys7f2`，白模场景保留）：
