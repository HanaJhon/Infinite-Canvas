# 无限画布素材采集（浏览器扩展）

在浏览器里浏览网页时采集图片，上传到本机「无限画布」应用的**个人素材库**。
Chrome / Edge，Manifest V3，无构建、无第三方依赖。

## 安装

1. 打开 `chrome://extensions/`（Edge 是 `edge://extensions/`）。
2. 打开右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选择本目录 `extension/`。
4. 点扩展图标 → 「设置 / 登录」→ 填服务地址（默认 `http://127.0.0.1:3000`）和账号密码登录。

## 用法

- **右键采集**：网页上右键任意图片 → 「采集到无限画布素材库」→ 弹出采集小窗口。
- **拖拽采集**：按住网页里的图片开始拖 → 页面右下角出现「拖到这里采集」→ 松手 → 弹出采集小窗口。
- **弹窗快捷采集**：点扩展图标 →「采集当前页图片」，自动扫描当前页可见的大图（≥80×80）并带入采集窗口。
- 采集窗口里可以：粘贴图片地址、删除单张、选素材库、选图片分类、**新建分类**，点「确认采集」后逐张上传，最后一次性入库。
- 结果会显示「已采集 N 张到 <素材库>/<分类>」；失败的单张留在列表里并给出原因。

## 设置

- 服务地址默认 `http://127.0.0.1:3000`，改完点「保存地址」；「检测连接」会顺手报出登录状态。
- 地址与令牌存在 `chrome.storage.local`（`baseUrl` / `token`）。
- 因后端 cookie 是 `SameSite=Lax`，扩展跨站请求带不上，所以所有请求都用请求头 `X-IC-Session: <token>` 鉴权；令牌失效（401）会清掉本地令牌并提示重新登录。

## 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 「连不上服务」 | 无限画布没启动，或地址/端口不对（本机默认 3000；不要填 `localhost` 之外的内网地址除非确实要连）。 |
| 「取图失败：无法访问该图片」 | 图片站点开了防盗链、需要登录，或图片是 `data:` 内嵌地址。可先在网页上右键「图片另存为」，或换一张同类图。 |
| 「不是图片（text/html …）」 | 该地址返回的是网页而不是图片字节（常见于需要登录或反爬的图床）。 |
| 网页右下角没有出现投放区 | 只在「从网页里拖图片」时出现；`chrome://`、扩展商店等浏览器内部页面不允许注入。如果拖的是链接文字或非图片元素，也不会出现。 |
| 「该素材库没有图片分类」 | 点「新建分类」建一个图片分类；`type=style` 的风格库不会出现在列表里。 |
| 上传报 413 | 单张图片超过服务端上限（`UPLOAD_MAX_MB`），换小图或调服务端上限。 |
| 修改代码后没生效 | 到 `chrome://extensions/` 点该扩展的「刷新」，再刷新原网页（内容脚本要重新注入）。 |

## 文件

| 文件 | 职责 |
| --- | --- |
| `manifest.json` | MV3 清单：权限、service worker、内容脚本、弹窗/设置页、图标。 |
| `background.js` | service worker：右键菜单、取图字节、调用登录/素材库/上传/入库接口，所有网络请求都在这里。 |
| `content.js` / `content.css` | 页面内拖拽采集：`dragstart` 时显示右下角投放区，`drop` 后通知后台开采集窗口。 |
| `capture.html` / `capture.js` | 采集小窗口：缩略图列表、选素材库/分类、新建分类、确认采集与结果反馈。 |
| `options.html` / `options.js` | 设置页：服务地址、登录/退出、检测连接。 |
| `popup.html` / `popup.js` | 点扩展图标：登录态、采集当前页图片、打开采集窗口与设置。 |
| `common.js` | 页面端公共：和后台通信、登录表单绑定、提示样式。 |
| `ui.css` | 采集窗口/设置/弹窗共用样式。 |
| `icons/` | 16/48/128 占位图标（纯色 PNG，可自行替换）。 |

## 说明

- 只做「图片 → 个人素材库」。团队库、风格库、工作流分类都不在范围内（风格库会在列表里被过滤掉）。
- 入库用 `POST /api/asset-library/items/batch`，分类必须是 `type=image`，否则后端返回 400。
